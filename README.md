## karpathy-output-discipline

让 AI 规范地做事、规范地表达的 skill。以 Karpathy 四原则（先想后做、简单优先、外科手术式修改、目标驱动）为骨架，结合 superpowers、mattpocock/skills、caveman、humanizer、i-have-adhd、stop-slop 等高星项目，补上四条表达规则（结论先行、只说有用的、有证据才下结论、写人话）。

- Skill：[`skills/karpathy-output-discipline/SKILL.md`](skills/karpathy-output-discipline/SKILL.md)
- 调研笔记：[`docs/karpathy-ai-output-research.md`](docs/karpathy-ai-output-research.md)

### 安装（Claude Code）

所有项目可用：

```bash
mkdir -p ~/.claude/skills
cp -r skills/karpathy-output-discipline ~/.claude/skills/
```

只在某个项目用：

```bash
mkdir -p .claude/skills
cp -r skills/karpathy-output-discipline .claude/skills/
```
